# Investigación definitiva de electricidad y electrificación CDMX

**Corte documental: 8 de octubre de 2026.** Alcance: costos eléctricos y clasificación de electrificación; no rendimientos de vehículos (cubiertos por otro integrante).

## Archivos

- `evaluacion-dashboard.md`: auditoría del cálculo actual y propuestas de evolución.
- `facturacion-patios.md`: categorías, factura, demanda y escenarios.
- `costos-transporte.md`: evidencia de contratos/inversión y separación de costos.
- `inventario-electrificacion.md`: alcance de los registros y decisión de inclusión.
- `fuentes-consultadas.md`: ficha de cada fuente.
- `solicitud-informacion-publica.md`: texto de solicitud para obtener facturas y contratos.
- `diccionario-datos.md`: campos y claves para ingestión futura.

Los CSV están en `data/electricidad-cdmx/`. Las celdas vacías significan **desconocido** y nunca equivalen a cero. No se ha obtenido factura de un patio concreto: `facturas-verificadas.csv` contiene sólo encabezados, intencionadamente.

**Regla del proyecto:** una ruta no se excluye de electrificación sin evidencia de flota completamente eléctrica; y una inversión en estaciones no se debe dividir entre kWh y publicar como tarifa.
